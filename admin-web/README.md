# Primakov School — Admin Web

> **Единый центр администрирования образовательной экосистемы Гимназии им. Е.М. Примакова**

Веб-панель управления предоставляет администрации, завучам и координаторам полный контроль над всеми цифровыми сервисами школы: расписанием, успеваемостью (МЭШ), сервисными заявками, столовой, пансионом, Кубком Домов и публикациями.

---

## 🏛️ Ключевые возможности

### 1. Дашборд здоровья продукта (Product & Campus Health)
- **Системный пульс (System Pulse)**: Мониторинг доступности API (latency в мс), статус пула соединений PostgreSQL и актуальность синхронизации с МЭШ.
- **Продуктовые KPI**:
  - **DAU (Активность сегодня)**: количество и процент активных пользователей онлайн.
  - **Посещаемость занятий**: оперативный процент присутствия учащихся (целевой порог $\ge 95\%$).
  - **SLA сервисных заявок**: процент заявок, закрытых в нормативный срок ($<24$ч).
  - **Индекс качества CSI**: средний балл удовлетворенности сервисами кампуса.
- **Монитор нагрузки и трафика (Traffic Pulse)**: График активности по дням и часам с разделением потоков «Ученики» и «Учителя».
- **Виджет «Требует внимания» (Actionable Alerts)**:
  - Срочные неразобранные заявки Service Desk ($>12$ч) с кнопкой быстрого перехода.
  - Своевременный контроль замен в расписании на сегодня.
  - Статус вечерней переклички кампусного пансиона.
- **Здоровье модулей экосистемы (Module Vitals)**: Мониторинг предзаказов столовой, покрытия уроков и турнирной таблицы Кубка Домов.

### 2. Управление пользователями и контингентом (User Directory)
- Просмотр и фильтрация контингента по ролям (`STUDENT`, `TEACHER`, `ADMIN`, `SUPERADMIN`).
- Полнотекстовый поиск по ФИО, классу, email и контактам.
- Профиль пользователя: детальная карточка с ДР, возрастом, контактами и сегодняшним расписанием уроков.
- Пакетный импорт пользователей из CSV с автоматической валидацией строк.
- Экспорт актуальной базы пользователей в CSV.
- Интеграция с МЭШ: модальное окно импорта и синхронизации учебных оценок.

### 3. Расписание и замены (Timetable & Subjects)
- Управление предметами, кабинетами и назначением учителей.
- Интерактивная матрица расписания по классам и дням недели.
- Добавление, редактирование и удаление уроков без перезагрузки.
- Оперативное оформление замен преподавателей.

### 4. Сервисный стол заявок (Campus Helpdesk)
- Обработка тикетов по трем категориям: IT-поддержка, обслуживание помещений, клининг.
- Приоритизация (`LOW`, `MEDIUM`, `HIGH`, `URGENT`) с цветовой индикацией.
- Назначение исполнителей, смена статусов (`PENDING` $\rightarrow$ `IN_PROGRESS` $\rightarrow$ `COMPLETED`).

### 5. Столовая и питание (Canteen & Nutrition)
- Управление недельным меню столовой по дням недели и типам питания (Завтрак, Обед, Полдник, Ужин).
- Контроль калорийности, белков, жиров, углеводов и маркировка аллергенов.
- Мониторинг предзаказов рационов питания гимназистов.

### 6. Обратная связь и CSI учителей (Teacher Ratings)
- Просмотр отзывов и оценок, оставленных учениками.
- Инструменты модерации: скрытие некорректных отзывов, расчет среднего балла CSI кафедр.

### 7. Объявления и Истории (Announcements & Stories)
- Публикация объявлений для учеников, учителей и родителей с категоризацией (Кампус, Учеба, Спорт, Мероприятия).
- Управление мультимедийными Stories (Instagram/Telegram style): загрузка обложек, установка ссылок перехода.

### 8. Кубок Домов (House Cup)
- Турнирная таблица 4 Домов: «Север», «Юг», «Восток», «Запад».
- Начисление и списание баллов за академические, спортивные и творческие успехи с фиксацией причины в журнале транзакций.

### 9. Пансион и увольнительные (Boarding Life)
- Мониторинг вечерней переклички и статусов проживающих (`PRESENT`, `LATE`, `ON_LEAVE`, `ABSENT`).
- Рассмотрение и согласование увольнительных записок на выходные дни.

## 📱 Мобильная адаптивность (Mobile Ready)

Веб-панель оптимизирована для использования на смартфонах и планшетах:
- **Адаптивный Sidebar Drawer**: на экранах $<1024$px боковое меню скрывается в off-canvas шторку с плавным выездом по клику на гамбургер-иконку или свайпу.
- **Mobile Bottom Navigation Bar**: нижняя панель быстрой навигации между ключевыми экранами (*Дашборд*, *Заявки*, *Расписание*, *Ученики*, *Еще...*).
- **Пластичные сетки**: адаптация карточек KPI и блоков метрик в вертикальный поток без горизонтального скролла.

## 🛠️ Технологический стек

| Компонент | Технология |
|---|---|
| **Фреймворк** | React 19 + TypeScript 5.3+ |
| **Сборщик** | Vite 8 + Fast HMR |
| **Стилизация** | Tailwind CSS v4 + кастомная палитра Primakov Crimson |
| **HTTP Клиент** | Axios с JWT Interceptor, авто-ретраями и перехватом ошибок |
| **Иконки** | Google Material Symbols Outlined |
| **Интернационализация** | Собственный легковесный `LanguageContext` (полная поддержка RU / EN) |
| **Отказоустойчивость** | `ErrorBoundary` для изоляции сбоев разделов + Демо-режим (Offline Demo Fallback) |

## 🚀 Запуск и сборка

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
По умолчанию приложение доступно по адресу `http://localhost:5173`.

### Сборка для продакшена
```bash
npm run build
```
Готовые оптимизированные статические файлы будут скомпилированы в директорию `dist/`.

### Проверка типов и линтинг
```bash
npm run lint
```

## ⚙️ Конфигурация окружения

Создайте файл `.env` в корне `admin-web/` при необходимости переопределить адрес API:

```env
VITE_API_URL=http://localhost:3000/api
```

Если сервер недоступен, веб-панель автоматически активирует **Автономный интерактивный режим (Demo Mode)**, позволяя тестировать все функции, фильтры и модальные окна без сбоев.
