Папка `.docs` содержит архитектурные отчеты, спецификации экранов и результаты технических аудитов приложения PrimakovApp.

  - Архитектура Clean Architecture и Result Pattern на Node.js/Express
  - Спецификация REST API для профиля (`/api/users/me/*`)
  - Связка с Flutter & Riverpod (модели, сервисы, провайдеры)
  - Интерактивные компоненты (фото профиля, уведомления, активные сессии, 2FA, помощь, документы)
  - Результаты тестов и верификации
